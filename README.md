# **Learning Faces**

A simple yet effective **Face Recognition System** built using a **custom dataset** (images of classmates) and the **Haarcascade Frontal Face Classifier**.
The project uses the **K-Nearest Neighbors (KNN)** algorithm to train a facial recognition model capable of identifying individuals based on their face data.

---

## **Project Overview**

**Learning Faces** is an end-to-end face recognition system that:

* Uses a custom real world dataset
* Detects faces using `haarcascade-frontalface.xml`
* Extracts and stores face embeddings
* Trains a machine learning model using **KNN**
* Predicts the identity of a person in real time

This project demonstrates the fundamentals of **face detection**, **feature extraction**, and **classification** using classical ML techniques.
